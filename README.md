# Skibidevs

https://shaiyon69.github.io/

Static GitHub Pages site, no build step:

- `/apptic/` app store (`data/apptic.json`, downloads from each app's latest GitHub release)
- `/playroom/` Convallaria web build (`webvallaria/`)
- `/scrappbook/` dev logs (`data/logs.json`, `data/posts.json`)
- `/appendix/` other projects (`data/projects.json`)

Run locally: `python -m http.server` from the repo root, then open http://localhost:8000/.
